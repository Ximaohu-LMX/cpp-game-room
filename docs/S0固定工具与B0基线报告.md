# S0 固定工具与 B0 基线报告

测试日期：2026-09-27 UTC。对应 #8 S0；只接入既有测量版本、改造客户端与采样工具，未实施 S1–S6 或服务端性能优化。

## 1. 可复核的结论

500 bot 三轮采样均保持 **500–500 条连接、4 个工具工作线程、6 个工具进程线程、0 次非预期断线**。每轮请求采样 60 秒，实际指标窗口约 59 秒；这不是 #8 S6 的长时稳定性验收。
原服务端在新工具下的 B0：循环频率 **14.37–15.08 Hz**，整轮工作 P99 上界 **52.33–57.57 ms**，输入等待 P99 上界 **84.28–92.71 ms**。后续优化应与本次 B0 比较，工具变化需要重测 B0。

表格来自 [summary.json](performance/2026-09-27-s0/summary.json)；[原始归档](performance/2026-09-27-s0/raw-measurements.tar.gz) 含每轮两端 JSONL、资源采样、日志、命令和脱敏配置；[环境](performance/2026-09-27-s0/environment.json)、[验证](performance/2026-09-27-s0/validation.json)、[校验和](performance/2026-09-27-s0/SHA256SUMS) 保留版本与测试证据。

## 6. 状态恢复采样与回归边界

B0 循环对战关闭了模拟断线，重连尝试数为 0；因此本次 B0 **未取得真实服务端状态恢复成功率或恢复 P99**，不能把空分布写成 0 ms。S0 只为后续 #8 S4/S6 提供采样能力。

受控协议端点的 18 次恢复尝试中：4 次收到有效状态、2 次无房间、2 次拒绝、4 次超时、2 次终局、4 次房间/帧错误；成功响应 16 次，状态恢复只计 4 次。验证包含状态先于/后于响应、逐段拆包，以及快照缺少本玩家时不能成功。该数据是工具自动化测试的预期结果，**不是 B0 真实服务器的重连指标**。

恢复事件记录前后 room/frame/hp；当前只检查同一房间、包含本玩家、帧不倒退，不验证 HP 是否被错误重置，也未验证 Waiting/Settlement 等所有状态语义。种子控制每 bot 随机流，不控制服务器随机性或全局匹配次序。

- C++：23/23 通过，0 跳过，见 [日志](performance/2026-09-27-s0/cpp-tests.log)、[XML](performance/2026-09-27-s0/cpp-tests.xml)。

## 7. 后续复测与简历使用

先按 [测量说明](measurement.md) 构建所声明的两个版本。复用本次 bot ELF（校验 SHA256）和冻结脚本，替换服务端版本即可；保持数据库持久化配置、负载参数、种子和采样窗口一致。完整实测命令见 [baseline-command.json](performance/2026-09-27-s0/baseline-command.json)。

```bash
python3 scripts/measure_baseline.py \
  --server /path/to/B0/game_server --bot /path/to/frozen/game_bot \
  --server-revision 2703dd38d864071b20021f5897658cbc7619a1bd \
  --bot-revision 591dc3aa1c5ed94fcab4a1eed30d657a7b9cd949 \
  --config /path/to/dedicated-test.yaml --output /tmp/b0-new \
  --counts 50,200,500,500,500 --warmup 20 --seconds 60 \
  --bot-threads 4 --seed 20260927
```

目前这份报告支持网络条目中的：**“500 并发连接三轮短时循环对战采样均无非预期断线。”** 面试中应同时注明每轮约 59 秒有效窗口。客户端线程池仅作为测试设施，不纳入服务端优化简历条目。不能填入“稳定 20 Hz”、长期稳定容量、真实重连成功率，也不能将工具带来的差值计入服务端优化收益。
